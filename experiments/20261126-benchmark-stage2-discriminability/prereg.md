## B. 推定対象と出力の分類

- C_m = 固定した schedule の上で、全出力を分母にした target − foil の対比。各 battery の凍結の単位・セル・重みのまま
  (v2・v3 = `component_scores`・`family_units`、G = `arm_unit_scores`・`unit_scores`、O_time = `cell_scores`・`unit_scores`)。
  セルの得点は凍結の `category` で決まる (target = +1、foil = −1、それ以外 = 0)。
- **主たる推定対象** = 同じ battery・同じ割付の上での C_m − C_m'。
- 出力の排他的な分類 (arm・書き方ごと): target / foil / Ω 内の残り / Ω 外 / ⊥ / 通信の欠測。
  q (target か foil を選んだ率) と r (その中で target の率) を診断として報告する (C = q(2r − 1))。
- **r の差の感度条件** (「属性への反応の差」と書く条件、`stats.decide_battery` の `sensitivity_ok`。ADR §2.2 の「許容範囲内で不利に割り当てても」を、
  許容範囲を定めずに**最悪の割当**に強めた。attack-me 監査 2-4): (1) で名指した対 (上位 a、下位 b) について、
  対の外のセル (Ω 内の残り・Ω 外・⊥) を、a は −1、b は +1 に割り当てて単位の値を作り直しても、同じ検定 (§D) が Δ_min で棄却するときだけ書く。
  満たさない対は「得点差」までで、その内訳が q の差で説明されうることを併記する。
- TV の差は主張しない (下界どうしの差は TV の差の下界ではない、ADR §2.2)。

## D. 多重比較と同時区間 (/reimagine のハイブリッド、DM-5)

- α = 0.05 (family-wise)。検定族 = 本走に入りうる battery × 入場モデルの順序対。
  **K = Σ_b M_b(M_b − 1)**。和は資格 (§A) で入場が 3 以上の battery について取り、pilot の gate で確定する。各片側の水準は α/K。
  - 予算で保留した battery (§G-5) と、本走で ⊥ の envelope を超えて外したモデル (§F-3) は K を減らさない (保守側。循環を避ける)。
  - (1) と (2) は同じ片側の限界を使うので、1 つの Bonferroni で両方の誤りを覆う。
- **区間**: 独立な単位の対差 x_u = X_{a,u} − X_{b,u} ∈ [−2, 2] の平均 μ̄ に対する片側の下限。
  - E(m) = (1/12) Σ_j Π_u (1 + λ_j (x_u − m))、λ_j = c_j / (m + 2)、c_j = 0.98 · 0.7^j (j = 0..11)。
  - 下限 L = inf{m : E(m) < K/α}。
  - **単調性**: 因子 = (1 − c_j) + c_j (x_u + 2)/(m + 2) は m について非増加なので、E は m について非増加 (test `test_e_value_nonincreasing_in_m`)。
    よって「L ≥ t」は「E(t) ≥ K/α」と同値で、判定は点 t での検定の形で計算する。
  - **有効性 (定理)**: 単位の x_u が独立で [−2, 2] に有界、単位の平均の平均が μ̄ のとき、固定の λ について
    E[Π_u (1 + λ(x_u − μ̄))] = Π_u (1 + λ(μ_u − μ̄)) ≤ 1 (各因子は非負。AM-GM)。混合も同じ。Markov で P(L > μ̄) ≤ P(E(μ̄) ≥ K/α) ≤ α/K。
    対称性・同分布・交換可能性・正規近似を仮定しない (単位の独立の下で、被覆は少数の単位でも成り立つ。ADR の Codex「少数単位での被覆率」)。
  - **系譜と、λ をデータに依らせない禁止** (attack-me R3): 有界の平均の betting による区間 (Waudby-Smith & Ramdas [71]) の系譜に当たる。[71] の予測可能な λ は、
    条件付き平均が一定の族の上で test supermartingale になる。本登録の帰無は単位ごとに平均が違う (弱い帰無) ので、予測可能な λ をそのまま使えず、
    **λ をデータに依らない固定の格子**にして AM-GM で示した。後の改修で λ をデータから選ぶ (予測可能にする) と、弱い帰無の下での有効性が壊れるので禁止する。
  - 既知解の test: 1〜3 単位の厳密な値・帰無での被覆 (有界の非対称な二点・異質な平均)・反転の一致。
- **推論の対象** (attack-me R1 M3 で書き直した): layout・表示順・書き方を固定した schedule に条件付け、**seed の列は事前に固定した擬似乱数の標本で、
  decoding の乱数の代理とみなす**。各単位の値は、その seed での decoding の 1 回の抽出とみなし、単位の間 (seed が違う) を独立とする理想化に立つ
  (G・O_time と同じ)。Ollama の decoding は seed を固定すると決定的になりうるが、その場合も「seed の選び方を乱数とみなす」理想化の下で同じ定理が使える。
  qwen3:8b の旧 seed の再生 (§C) は決定性の監査の記述で、区間の解釈を変えない。
  新しい layout・新しい項目への一般化は言わない。
- **独立な単位** (DU-12)
  - G: (族, つ組, r)。2 arm × 3 probe の 6 呼び出し (各 prereg の単位、seed・並びを共有しない)。1 replicate 16 単位。
  - O_time: (族, 部屋, r)。2 arm × 2 書き方の 4 呼び出し。1 replicate 12 単位。
  - **v2・v3: (r, probe, k)**。同じ seed を共有する全 lever arm (両族) を 1 単位にまとめる。1 replicate は v2 で 60 単位 (probe 6 × k 10)、v3 で 30 単位 (probe 6 × k 5)。
    単位の値 = 2 族の (s_a + s_a') / 2 の平均。単位の平均の平均は凍結の C と一致する (等しい重み)。
    同じ r の中の layout の共有は、schedule に条件付けて扱う (layout は確率変数ではない)。単位の間の独立は、別の seed の呼び出しが独立な抽出であるという理想化
    (v2〜v5・G・O_time と同じ) に依る。
  - **逸脱の記録 (DU-12、user 裁定 2026-11-26、実データ・pilot の前)**: design-final §D と ADR §2.3 は v2・v3 を replicate の cluster とした。
    この区間では、真の差 0.20 から下限 > 0.10 を power 0.8 で示すのに、σ = 0 でも独立な単位が約 205〜226 個要る (試算)。単位 = replicate では R ≥ 約 205 で、
    v3 は約 3.0〜3.3 時間、v2 は約 2.9〜3.1 時間かかり、予算 (§H) で G・O_time の後に入らない。v2・v3 は pilot のデータに依らず設計で外れ、
    DU-8 の「対称に測る」が空になる。ADR §2.3 の要求 (seed を共有する arm・族の結合を 1 単位に保つ・モデル間の対応を保つ) は満たす。
- 床・天井の帯の判定は、各モデルの C (単位の値 ∈ [−1, 1]) の両側の同時区間 (各側 α / (2 ΣM_b)、ΣM_b は入場したモデルの数の battery の和) で、同じ形の検定を使う。

## E. 信頼性と床・天井

- **split-half**: 位置の 1 巡を block にし (v2・v3 = 4 r、G・O_time = 3 r)、本走の r の範囲の始点から数えた block の偶奇で単位を 2 つに割る。
  本走の R は v2・v3 で 8 の倍数、G・O_time で 6 の倍数 (両半分で表示位置が均衡する)。
  - (1) で名指す順序対 (a, b) は、両半分で対差の点推定が > Δ_min のとき再現したとする (同じ符号の向きかつ Δ_min 超)。
  - 全順位の相関は要求しない (同点・全同点・相関の未定義の問題を避ける。ADR §2.4 の「要求する場合」に当たらない)。
- **床の帯** = [−0.10, 0.10]、**天井の帯** = [0.90, 1] (ローカルで観測する天井)。
  - **報告集合** (§F) の全モデルの C の同時区間が床の帯に入る、または報告集合の全モデルの下限が 0.90 以上なら、集中とする。集中なら (1) にしない。
    補正の分母 ΣM は K と同じく pilot の入場集合の本数で取る (Codex r4 MEDIUM-3)。
    (2) の条件を満たせば (2)、満たさなければ (3) (ADR §2.4、Codex r2 HIGH-3)。
  - 負の向きへの集中と、成分の相殺による 0 を区別して記述する: 床の集中のとき、各モデルの成分 (battery の凍結の成分。G は arm・probe、O_time は 4 成分、
    v2・v3 は arm) の標本平均と q を併記し、成分の符号が混ざるなら「相殺の可能性」、全成分が負なら「負への集中」と書く (記述で、判定に使わない)。

## F. 判定表 (battery ごと。上から順に当て、最初に当たったもの。`stats.decide_battery`)

1. **INVALID** (INVALID_SCORER / INVALID_TASK_BATTERY): 照合 (manifest・certification)・battery の機械検査 (本登録の r の列の上で)・meta (§A.1 の digest・template・options) の違反。
   モデル単位の meta の違反は、そのモデルをその battery の判定から外して INVALID として報告する (battery の判定は残りのモデルで続ける)。
2. **not_computed** (battery 全体): 全モデルで記録が無い・battery の記録の構造が欠ける。
   - **モデル単位の not_computed** (通信の欠測 = 同じ seed で 3 回まで再送して解けないもの・そのモデルの行の欠け・時間切れで走り終えていない) は、
     **そのモデルを報告集合から外して続ける** (DU-13、attack-me R1 M2・R2)。理由を列挙し、K は減らさない。
   - モデル単位の再実行は通信の not_computed のときに 1 回まで (§H)。再実行は、その (battery, モデル) の全記録の置き換えで、元の記録は判定に使わない。
3. **資格不足** (NOT_QUALIFIED): 入場 < 3、または報告集合 < 3。本走で lever arm (v2 は C0 を含む。各 arm ごと) の ⊥ 率が
   envelope = min(0.2, そのモデル・battery の pilot の lever arm の ⊥ 率の最大 + 0.05) を超えたモデルと、§F-1 の meta の違反のモデルと、モデル単位の not_computed のモデルを、
   その battery から外したあとで数える。「超える」は arm 別の数と呼び出しの数の整数の分数で、厳密な > で比べる (`stats.envelope_exceeded`。境界ちょうどは残す。
   見取り図も同じ関数を呼ぶ。凍結前の Claude reviewer の MEDIUM-1)。
4. **(1) 判別性を確立** (ESTABLISHED): ある順序対 (a, b) で E_{a−b}(Δ_min) ≥ K/α (下限 ≥ Δ_min。帰無 μ̄ ≤ Δ_min の棄却で、ADR の「下限が Δ_min を超える」と
   測度 0 の境界を除いて同じ) **かつ** split-half で再現 **かつ** 床・天井の集中でない。
   **条件を満たす順序対をすべて名指す** (DU-13、attack-me R2)。各対に §B の感度条件と §J の fixture の併記を個別に当てる。
5. **(2) 較正した否定** (CALIBRATED_NEGATIVE): 全順序対で E_{a−b}(−0.10) ≥ K/α (両方向の下限 ≥ −0.10、すなわち全対の区間が同等域の内)。
   報告集合が pilot の入場集合より小さいときは **CALIBRATED_NEGATIVE_ON_SUBSET** とし、外したモデルの数を出力に必ず入れる (DU-13、attack-me R3)。
   `stats.decide_battery` は pilot の入場集合の本数 `n_entered` を必須の引数に取り、K ≥ n_entered (n_entered − 1)・ΣM ≥ n_entered・報告集合 ≤ 入場集合を検査し、
   外した本数 `n_excluded` を返す (省略して全体のラベルが出る経路を塞ぐ。Codex r4 HIGH-3)。
6. **(3) 決着しない** (INCONCLUSIVE): それ以外。

- **本走に入らなかった battery の報告の語** (attack-me 監査 1-1): pilot の gate で STOP (power) の battery は「この雑音と予算の R では検定を起こせない
  (設計容量)」、HELD_COST の battery は「予算の外 (未実行)」と書く。どちらも判別性について何も言わない。資格不足 (pilot で入場 < 3、または本走の報告集合 < 3) は「資格不足」と書く。
- **記述として必ず出すもの** (判定に使わない。DU-13、attack-me R2・R1・R3)
  - 報告集合の全順序対: 対差の点推定・両方向の片側下限・単位の数。
  - モデルごと: C の両側区間 (§D の形、各側 α/(2ΣM))・q・r・出力の 6 分類。
  - モデル間の単位値の相関 (対ごと)。
  - v2・v3: 単位を replicate の平均にした同じ形の対差の下限 (`stats.replicate_lower_bounds`)。(1) の名指しが単位の選び方 (DU-12) に依るかを併記する。
  - (1) で名指した対の q の差と r の差。
- **(2) の power は保証しない**: R は (1) の power だけで選ぶ (§G-4)。現実的な雑音では、全モデルが同じでも (2) に届かず (3) が既定の結果になりうる
  (§I.2 表 3 の `all_equal`・中・indep)。spike-in は記述として 2 つを出す (Codex r4 MEDIUM-2): (i) 指定の一対 (最大分散の対) の対差 0 での両方向の下限 ≥ −0.10 の率
  (`SpikeRow.p_pair_equiv_at_zero`。一対の診断で、battery の (2) の率ではない)、(ii) 全モデル同点の注入での P((2)) (`stats.spike_negative_all`:
  入場モデルを項目ごとに中心化して同じ係数で膨張し、全モデルで同じ単位の添字を抽出してモデル間の対応を保ち、全順序対が同等域の内かつどの対も Δ_min の検定で棄却されない率。split-half と集中は見ないので (2) を厳しく数える)。
  (ii) は選んだ R (STOP (power) なら候補の最大の R) で出す。どちらも R の採否に使わない。

- 運用上の終了 (線の単位): どの battery も (1) でないとき、「**登録したモデル・予算で、判別性を確立できずに終了**」と書く。
  予算の停止で止まったときは §F-2 の規則による (Codex r4 HIGH-2): 走り終えていない (battery, モデル) だけをモデル単位の not_computed として報告集合から外し、
  残りのモデルを §F に通す。全モデルの記録が無い battery (未着手を含む) だけが battery 全体の not_computed。
- (2)・(3) のどちらでも、天井の問いは BL-1 に残す。
- **2 つのモデル集合を分けて記録する** (Codex r1 HIGH-1)
  - **pilot の入場集合** (§A。K と ΣM を決める) と、**本走の報告集合** (pilot の入場集合から、本走で meta の違反 (§F-1)・モデル単位の not_computed (§F-2)・
    ⊥ の envelope の超過 (§F-3) で外したモデルを除いたもの)。床・天井の集中の判定 (§E) も報告集合のモデルで見る (ΣM は K と同じく pilot の入場集合で取る)。
  - (1)・(2)・(3) の判定と報告文は、報告集合の上のものである。(2) の報告文には報告集合のモデル名と分母 (報告集合の本数 / pilot の入場集合の本数) を入れ、
    外したモデルは理由 (meta の違反 (INVALID)・⊥ の envelope の超過・モデル単位の not_computed (時間切れ・通信の欠測・行の欠け)) とともに列挙する。外したモデルの対について同等性は何も言わない。
  - K は pilot の入場集合で確定し、外したモデルの分を減らさない (多重性に対して保守側。外した対の同等性を示す効力はない)。
    K の和は資格 (§A) で入場 ≥ 3 の battery 全部について取り、pilot の gate で STOP (power) や HELD_COST になった battery も含む (Plan の「本走に入った battery」より
    広い保守側の変更。attack-me 監査 2-1)。
- **枝ごとの誤り率の主張**: 「報告集合の中で、真の差が Δ_min 以下の順序対を (1) で名指す、または真の |差| ≥ 0.10 の対があるのに (2) と言う、のどちらかを 1 つでも出す頻度」は、
  §D の Bonferroni で族全体 α 以下である (どちらも、その順序対の帰無 (μ̄ ≤ Δ_min、または μ̄ ≤ −0.10) の下での棄却の事象に含まれる)。
  これは判定を出した後の条件付きの誤り確率ではない。
- split-half と集中は、**観測の上の追加条件**である (Codex r1 LOW-2)。(1) を減らす方向にだけ働くので、誤った名指しを増やさない。
  報告では「両半分の**点推定**が Δ_min を超え、登録した**集中の条件に当たらなかった**」と書き、真の値についての主張にしない
  (例: 真の全モデルが床の帯にあっても、端の −0.10 と +0.10 にモデルがあれば真の対差は 0.20 で、集中を検出せずに (1) に進みうる)。
- §I で模擬で確かめる。

### G.2 順に当てる (`results/pilot/gate.json`、次のタスクの pilot gate が本 module の関数で計算する)

1. **STOP (records)**: certification・meta・schema・構造の違反。
2. **not_computed**: 通信の欠測・欠け。
3. **資格** (§A): battery ごと・モデルごとに `stats.qualify`。入場 < 3 の battery は以後外す。K を確定する (§D)。
4. **battery ごとの R の選定** (spike-in、`stats.select_r`)
   - pilot の lever arm の単位の値 (§D の単位、モデルごと) から、入場したモデルの対で pilot の対差の標本分散が最大の対を選ぶ
     (**最大分散の対による条件付きの計画**。最小の power を保証するものではない。Codex r1 MEDIUM-1)。
   - **中心化と抽出の単位** (DU-13、attack-me R3): 中心化は**項目ごと** (v2・v3 = probe、G = 族・つ組、O_time = 族・部屋) に行い、
     抽出は**表示の回転をまたいで項目の中でプール**する (G・O_time は回転ごとだと 4 点しかないので、項目の中の 12 点から抽出する。v2・v3 は 120・60 点)。
     項目ごとの本走の単位の数は保つ。表示位置の均衡は本走の割付で保たれるので、抽出では回転を区別しない。
   - その対差を**両方向** (d と −d) で使う。各方向で項目ごとに中心化し、**登録した計画上の膨張係数** sqrt(11 / χ²_{0.05, 11}) ≈ 1.55 を掛ける
     (正規の下の σ の 95% 上限の式の値を、R_pilot = 12 の自由度 11 で 4 battery に共通に使う。有界で異質なデータで 95% の被覆を証明した σ の上限ではない)。
   - 抽出先の枠は本走の割付の単位 (項目ごとの本走の単位の数を保つ)。各枠の値は、**同じ項目の pilot の全回転の単位のプール**から復元抽出する (Codex r4 LOW-1)。
   - **既知量への較正** (Codex r1 HIGH-3): 各方向・各目標 t ∈ {0.20 (power)、0.10 (size)} について、本走の層の重みで
     mean(clip(b + e, −2, 2)) が t に一致する移動 b を、pilot の経験分布の上で二分法で先に解く (b について非減少)。解けなければその R は不合格。
     x = clip(b_t + e*, −2, 2) とする (素朴に b = t と置くと、非対称な残差では clip で 0.10 の行の真の平均がずれ、対立仮説のデータで size を測ることになる)。
   - 合格の条件 (3 つすべて)
     - power: 2 方向の小さい方の P̂ = P(E(Δ_min) ≥ K/α ∧ split-half で再現) について、**P̂ − 2·MCSE ≥ 0.8** (MCSE = sqrt(P̂(1 − P̂)/N)。DU-13、attack-me R3)。
     - size: 2 方向の大きい方で、t = 0.10 の棄却の数 ≤ x̄ (Bin(N, α/K) で P(X > x̄) ≤ 0.01/2 の最小の x̄)。
     - 較正: 4 行 (2 方向 × 2 目標) の実現した平均 (N 回の MC の x の平均の平均) と目標の差の最大 ≤ 0.01。
   - gate の出力に、各 R の行の 2 方向の power・2 方向の size の棄却の数・4 つの b と 4 つの実現した平均を残す (`SpikeRow`。最大の較正誤差と最大の棄却の数は
     これらから再計算でき、合否に使った値と一致する (test)。Codex r2 MEDIUM-1)。
   - 記述 (判定に使わない): clip の後の対差の標準偏差 (膨張の前の値と並べる)・指定の一対の対差 0 での両方向の下限 ≥ −0.10 の率と、
     全モデル同点の注入での P((2)) (§F の (2) の power の参考。§F の (i)・(ii))。
   - 候補 = 本走の R の刻み (v2・v3 = 8、G・O_time = 6) の倍数で、名前空間の上限 (G 36、O_time 672) と、その battery 単独の予算の上限 (**1 モデルあたり 8B 換算 3 時間**) まで。小さい順に当て、
     3 条件を満たす最初の R を選ぶ。無ければ **STOP (power)** (その battery は本走に入れない)。
   - N = 2,000、乱数の seed = 20261126 (固定)。
5. **予算**: **1 モデルあたり**の 8B 換算の費用 = 段 1 の 1 呼び出しの秒 × 1 replicate の呼び出し × R。4 battery の費用を安い順に足し、
   **1 モデルあたり累計 3 時間**以内まで本走に入れる (GO)。超えた battery は保留 (HELD_COST)。全 6 モデルでは最大 18 時間 (§H)。

     G = lever 4 arm (96)、O_time = lever 4 arm × 2 書き方 (48)。判定 (C) は lever (v3 は judge) arm だけで、C0・L arm は envelope (v2 の C0 は §F-3 に含む)・
     記述に使う。費用はこの呼び出し数で数える。
   段 1 の ADOPT / HOLD は使わない (DM-6)。

  pilot の σ の不確実性は σ_up 倍で入れる。選定の自由度は R だけ (注入法・候補・順序は実データ前に固定)。pilot の記録は確認に使わない。

### I.1 模型・形・規則 (回す前に固定)

- **生成の模型**: 単位 = 対 n_p 個の平均 (v2・v3・O_time = 2、G = 3)。対の値 ∈ {+1, 0, −1} (0 は相殺・⊥・Ω 内の残りをまとめた)。
  モデル m の単位 u の平均 μ = C_m + h·z_u (z_u = ±1 を単位の順に交互、固定の schedule)、P(+1) = (g_m + μ)/2・P(−1) = (g_m − μ)/2、
  g_m = min(1, |C_m| + h + e) (相殺しない率)。実現する C は目標と一致する (test)。
- **雑音の格子** (h, e) ∈ {(0, 0) 低、(0.2, 0.3) 中、(0.3, 1.0) 高} × 結合 {crn (z と対の一様乱数をモデル間で共有)、indep (独立)}。
  **最も有利な行 = 低・crn** (小さい σ)。
- **形** (6 モデル、基準 0.3): 全同一 / 1 モデルだけ違う (+0.10 = 境界、+0.20) / 単調 (0.2〜0.6) / 族 (2 本だけ +0.20) / 同点 (0.3・0.3・0.4・0.4・0.5・0.5) /
  0 点率の違い (C は同じで 3 本の g = 1) / 床 (全 0) / 床で 1 本だけ +0.20 / 天井 (全 0.97) / 負の向き (−0.3 で 1 本だけ +0.20) / 選別 (入場 3・4・5、1 本だけ +0.20)。
- K = M_p(M_p − 1) + 3·6·5、ΣM = M_p + 3·6 (M_p = 対象の battery の pilot の入場。他の 3 battery が各 6 本入場した場合を足す。
  M_p に対して K が最大なので、**対差の検定の閾値が最も厳しい**。size は K に依らず §D の定理で守られる。Codex r1 HIGH-2)。
  - ΣM を大きくすると床・天井の集中を検出しにくくなり、(1) を止める条件は弱まる。したがって K と ΣM を同時に最大にしても、(1) の P が保守側になるとは限らない
    (Codex r2 MEDIUM-2)。保守側と言えるのは対差の検定の閾値だけである。
- **入場から最終判定まで**: pilot の入場集合で K・ΣM を決め、本走で外れたモデルを除いた報告集合で判定する。誤りは報告集合の中の対で数える (§F)。行は 2 種類ある。
  - **集合を指定した条件付きの行** (`drop_*`・`select_*`・`lookup_3`、Codex r1 HIGH-2): 外れるモデル・入場の人数を入力で固定する。除外の規則は当てない。
  - 差のあるモデルだけが外れる (pilot 4 本 (0.3・0.3・0.3・0.6) → 0.6 が外れ、報告集合 3 本)。
  - 差のないモデルが 1 本外れる (1 モデルだけ +0.20 の 6 本 → 5 本)。
  - 報告集合が 2 本に減る (pilot 3 本 → 2 本: 資格不足)。
  - lookup・資格の失敗は、入場の人数 (選別 3・4・5) として表す (失敗したモデルは pilot の入場集合に入らない)。
    `select_*` は対象の battery 固有の資格で減った場合 (他の battery は 6 本、K = M_p(M_p − 1) + 90)。
    **共通の lookup で 3 本だけが通る場合**は、他の battery も最大 3 本なので K = 3·2 + 3·3·2 = 24・ΣM = 12 (`lookup_3`、Codex r2 HIGH-1)。
  - **登録した規則を試行ごとに当てる行** (`rule_bot_*`、Codex r2 HIGH-1・r3 HIGH-1): **arm 別の ⊥ の数**を合成し (pilot の lever arm の呼び出しの数の二項。
    v2 は C0 を含む 5 arm × 720、v3 は judge 4 arm × 360、G は 4 × 288、O_time は 4 × 144。本走は 1 replicate あたり 60・30・24・12 × R)、
    §A.3 の規則 (arm 別の ⊥ 率の最大 ≤ 1/5 かつ族内の差の最大 < 3/40) で試行ごとの入場集合と K を決め、§F-3 の規則
    (本走の各 arm の ⊥ 率 > min(1/5, pilot の最大 + 1/20) なら除外) で報告集合を決める。比較は整数の分数で正確に行う (境界の浮動小数の誤差を避ける)。
    - 得点の ⊥ は対ごとに確率 b で起き、その対の値を 0 にする (⊥ を含めた真の C は (1 − b)·C)。arm 別の ⊥ の数と得点の ⊥ は**率 b だけを共有**し、
      どの出力が ⊥ かの結び付きは模型に入れない (限界)。
    - 実際に判定に使った (K, ΣM) の組とその試行数を `K_counts` に、選別の前の全試行の実現した C と (1 − b)·C の差を較正に残す (Codex r3 MEDIUM-1・2)。
      表の K・ΣM の欄は全候補が入場した場合の上限である。
    - `rule_bot_diff`: 5 本は ⊥ 0・C 0.30、1 本だけ ⊥ 0.19・C 0.55 (真の C 0.4455)。差のあるモデルが規則で外れたり残ったりする。
    - `rule_bot_all`: 6 本とも ⊥ 0.18 (5 本は C 0.30、1 本は 0.55)。入場と除外が試行ごとに揺れ、資格不足にもなりうる。
    - KNOW・L arm・masked の資格はこの模型に入れていない (族内の ⊥ 率の差は arm 別の数で入れた。`stats.parse_rule`) (どれもモデルを入場から外す向きにだけ働き、入場の人数の行で代表させる)。
- **指定の一対の power** (Codex r1 MEDIUM-1): P((1)) はどれかの順序対を名指す確率なので、真の差が最大の順序対を名指す確率 P(指定の一対) を併記する。
  止める条件は P(指定の一対) で判定する。真の差の無い行 (全同一など) と規則の行では P(指定の一対) を定義しない (null)。
- R の格子: v2・v3 {8, 16, 32}、G {12, 24, 36}、O_time {12, 24, 48}。回数 N = 2,000、seed は (battery, R, 形, 雑音) の sha256 から固定。
- **出力**: P((1))・P((2))・P((3))・P(資格不足)・P(指定の一対)、(1) の size (真の差 ≤ Δ_min の対を名指した数)、(2) の size (真の |差| ≥ 0.10 の対があるのに (2) と言った数)、
  端点でも読める二項の片側 95% の限界 (Clopper-Pearson。0 / N でも上限が出る)。
- **size の保証と MC の検査を分ける** (Codex r1 MEDIUM-2)
  - size の保証は §D・§F の定理による (上限 α)。見取り図は size を保証しない。
  - MC の検査は**実装の異常を見つける**ためのもの: 棄却の数 X ≤ x なら合格 (Bin(N, α) で P(X > x) ≤ 0.01/G の最小の x、G = size の点の数)。
    この規則は誤棄却 (正しい実装を落とす率) を族全体 0.01 以下に抑えるが、α を少し超える誤りは見逃しうる。どれだけの超過をどの確率で見つけるかを §I.2 に登録する
    (真の誤り率 p = 0.075・0.10・0.15 の点を不合格にする確率)。
- **止める条件 (door-close)**: どれかの battery で、最も有利な行 (低・crn) の「1 モデルだけ +0.20」の P(指定の一対) が、格子の最大の R で 0.8 に届かなければ凍結しない (user に戻す)。
  - 正直な読み (attack-me R3): 低の雑音は単位の値をほぼ目標で決めるので、この条件は実質「格子の最大の R の単位の数が、σ = 0 でも要る約 205〜226 単位に届くか」の検査で、
    雑音の情報を使わない。雑音を使う判定は pilot の spike-in (§G-4) が行う。
  - Plan の「予算内の R」から「格子の最大の R」に変えた (格子の最大は予算の上限より小さく、厳しい向き。attack-me 監査 2-2)。
  - この条件は「最良の場合でも届かない battery を実データの前に外す」ためのもので、pilot の R の選定の合格を意味しない。格子は恒真ではない
    (低・crn でも小さい R では届かない行がある、§I.2 表 2)。

## M. bridge と主張の上限 (ADR §5 の転記)

- 得点が表すもの: 固定した schedule の上で、全出力を分母にした、指定した属性 (規則・成否・構造・時期) が定める向きの target − foil の対比。
  - 対で消せるのは、各 battery で定理が 0 にする方策だけである。
    - v2: 登録した nuisance class (priming・label の事前傾向・表示位置・状態の最後の行) が 0 (合成 fixture で確認した範囲で、定理ではない。交互作用は保証しない)。
    - v3: 成否の欄を読まない方策は単位ごとに厳密に 0。成否を読むが weather と結び付けない方策は範囲外 (近傍方策 C = −1)。
    - G: probe key を見ない方策はどの単位でも d = 0。字面の方策は R 18 で最大 |C| = 0.0417 (段 2 の割付では §I.3)。
    - O_time: 札の数字を見ない方策 (定理 1) と、札の後ろの語を読まない方策 (定理 2) が 0。「目 / 前」と数字の対応を読む方策は残る。
  - 正の向きの τ-PASS を作れない方策でも、**モデル対の差**は作りうる (§I.3)。
- **着座** (本登録の語): モデルの実体 (§A.1 の digest・量子化。gemma2:9b は Q4_0、他は Q4_K_M)・template・think=False・
  temperature 0.7・top_p 0.8・top_k 20・repeat_penalty 1.0・num_ctx 4096・num_predict 32・Ollama 0.32.12 の組。
  族をまたぐ対の差は、この着座への適合の差を含みうる (例: num_predict 32 の打ち切りは冗長な族で ⊥ と q を下げうる)。
- **報告文に必ず入れる文言** ((1)・(2)・(3) のどれでも。DU-13、attack-me R2・R1)
  - 「この battery・この schedule (layout・表示順・書き方) に条件付けた。事前に固定した seed の列は decoding の乱数の標本とみなした (§D)。
    新しい layout・新しい項目への一般化は示さない」(Codex r4 MEDIUM-1)。
  - 「この着座の下で」(上の定義)。
  - 母集団は共通の lookup (§A.2) で限ったものである。O_time では、lookup に同じ battery の M0 の腕を使ったので、選別された母集団の上の結果である。
- **言えること** ((1) のとき): 「この battery・この schedule・この着座で、≲14B の、登録した入場モデルの間に、指定した属性が定める向きの得点差が、
  信頼性をもって出た (名指しした対。条件を満たす対をすべて)」まで。
  - r の差 (属性への反応の差) まで言うのは §B の感度条件を満たす対だけ。名指した対の q の差と r の差を常に併記する。
  - **v3 の (1) は「得点差」までに固定する** (属性への反応とは言わない。登録した方策の対 (近傍・直前/直後) で説明しうる差を排除できないため、§I.3。attack-me R1 M5)。
- **(2) のとき**: 「この battery・この schedule・この着座で、**報告集合** (モデル名を列挙、報告集合の本数 / pilot の入場集合の本数) の全対の得点差は ±0.10 の内」まで。
  - 本走で外したモデルとその理由を併記し、外したモデルの対については何も言わない (§F)。報告集合が小さいときの値は CALIBRATED_NEGATIVE_ON_SUBSET。
  - 「正答率に換算して最大約 5 ポイント (q = 1 のとき) の差は否定しない」と併記する (attack-me R2)。
  - 床・天井の集中の有無 (床・天井・なし) を必ず書く (attack-me R1 m1)。床の集中のときの (2) は「**報告集合の各モデルの C の同時区間が登録した床の帯
    [−0.10, 0.10] に入り、全対差の区間が同等域に入った**」と書き、§E の成分の標本平均と q を併記する。「属性の向きに動かない」とは書かない
    (C が床の帯の内でも、成分の正負の相殺で 0 になりうる。Codex r4 MEDIUM-3)。集中でないときは「**列挙した報告集合**の全対で差が同等域の内」(Codex r4 HIGH-3)。
- **(3) のとき**: 「決着しない」まで。線の終了は「登録したモデル・予算で、判別性を確立できずに終了」。
  **(3) のとき「判別しない」「差が無い」とは書かない** (「この範囲では判別しない」と書けるのは (2) のときだけ。ADR §2.5、attack-me 監査 1-3)。
- **向きの予測** (判定に使わない記述。DU-13、attack-me R1 M4): qwen3 の 4 段について、大きいほど C が高い (1.7b ≤ 4b ≤ 8b ≤ 14b) と予測する。
  - 報告の型: 名指した qwen3 の対ごとに「予測と一致 / 逆転」、4 段の点推定の順位が予測と一致するか (一致 / 不一致 / 同点を含む)。
  - 逆転した対は「得点差は大きさと逆向き。能力の差の証拠としない」と書く。族をまたぐ対の向きは予測しない。
- **言わないこと**: 「経験から学ぶ能力」「時間推論」「汎化能力」「推論力」。機構。TV の差。≲14B を超える一般化と天井。新しい項目・新しい layout への一般化。
  battery の間の序列。4 chain の verdict の書き換え。中核命題・身体性・3D の寄与。lookup で落ちたモデルについての判別。
- **再現の範囲**: 第三者が再現できるのは、記録からの判定 (2 回計算して byte 一致) までである。生成そのものの再現 (同じ seed で同じ出力) は GPU・版に依り、保証しない。
- **汚染**: 4 battery の語彙と課題は自作の合成 (新語彙) で、学習データに同じ項目がある見込みは低い。ただし確かめてはいない。
- **選択だけを採点する理由**: 次 token の確率を使う連続の指標は分散が小さくなりうるが、4 battery の凍結の scorer は閉集合の選択だけを採点するので、それに従う
  (battery を変えない)。
