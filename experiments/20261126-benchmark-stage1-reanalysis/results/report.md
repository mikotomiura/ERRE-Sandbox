## 3. 読みの注意 (規則を変えるものではない)

1. **v2 の HOLD は、R 4 の σ の不確実性で決まっている。**
   - σ_up は σ_rep の 2.92 倍である (χ² の自由度 3)。σ_rep のままなら、R_raw はおよそ 28 になる。
   - 規則は σ_up を使うと結果の前に決めたので、決定は変えない。
   - v2 は閉じていない。段 2 の後段で、または段 2 の pilot で σ を測り直して入れる候補として残る。
2. **σ は qwen3:8b の値である。** 他のモデルの σ は、その C の位置によって変わりうる。
   - σ = 1 (モデルに依らない上限) では、Δ 0.15 でどの battery も 7〜18 時間かかる (stage1.json の `hours_8b_sigma1`)。
   - 段 2 の R は、ここの R_cost でなく、事前登録の OC で決める (ADR §2.7)。
3. **R の表は、単一の battery で差 0 の対から Δ を識別する、1 対あたりの概算である** (rules.md §5)。
   - 段 2 の基準 (同時区間の下限 > Δ_min) と、複数 battery の検定族での power は、事前登録の OC で評価する。
4. **G と O_time の R_cost (12) は、凍結の本走の R (18・288) より小さい。**
   - これは、replicate の雑音が小さい (O_time は 1 replicate に 12 単位がある) ことによる。
   - 本走の R をそのまま段 2 に移す必要はないことを示唆する。ただし決めるのは段 2 の OC である。
