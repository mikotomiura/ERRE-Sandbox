# Issue 003: Stage 0 — Δ = T − S の分解とラベル層別 (適用範囲の pin つき)

verify_level: recheck

## Goal

`design-final.md` §1 の `T = 1 − rarity_full` / `S = 1 − rarity_LAO` / `Δ = T − S` を実装し、
**適用範囲が純 max-cos 候補に限られる**ことを test で pin する。
ラベル (good/common) 層別と `S_common − S_good` も出す。

## Background

**Codex HIGH-2**: `Δ = T − S` は `X1` (`agg="mean"`) には成り立たない。
**加えて自前確認 (DA-SC-9)**: `X2` は `_length_controlled` で
`rarity = base − (a + b·len(text))`。length 項は full/LAO で**相殺する**ので
**`Δ(X2) ≡ Δ(X0)`** だが **T/S 個別は復元できない**。
→ 対象は **`X0, X3a, X3b, X3c, C0, C4` の純 max-cos 候補のみ**。

**Codex MEDIUM-2**: LAO 後に survivor が空だと `embed_rarity` は `0.0` を返す。
したがって **`S = 1.0`** となる。この意味論を**凍結して docstring に書く**。

**Codex MEDIUM-1 / MEDIUM-5**: ラベル非依存の平均だけでは AUC collapse の機序を取り逃がす。
**common / good 別に出し、`S_common − S_good` も報告する**。
