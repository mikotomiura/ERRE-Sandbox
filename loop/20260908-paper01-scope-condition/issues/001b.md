# Issue 001b: 共有契約の穴埋め (Codex TASK-PRE HIGH-3/4/5 + MEDIUM-1) と節 anchor の設置

verify_level: recheck

## Goal

I-001 が凍結した共有契約のうち、**凍結済 ADR の要求を表現できていない 3 点**を埋め、
**I-002..I-006 が別々の節に追記できるよう anchor を先に置く**。
**fan-out (I-002..I-005 の並列実行) はこの issue の完了が前提**。

## Background

Codex TASK-PRE (`.steering/20260908-paper01-scope-condition/_codex-preplan.md`、Verdict **Revise**)
が HIGH 5 件を出し、うち 4 件を実物で検証して**実在を確認**した (DA-SC-16)。
本 issue はそのうち**コード側**の 4 点を担う (issue 本文側の修正は起票者が実施済)。

**最重要 = HIGH-3**。`design-final.md:165` は

> `X0 が replicate の過半で eligible でない` → **判定不能**として記録し、
> eligible な replicate に限った帯を**副**として報告

を凍結しているのに、`Stage1Result` に該当フィールドが無い。その結果
**判定不能が `deflation_supported=False` に潰れる**。
`design-final.md:251` の出口表は **「Stage 1 で deflation 棄却」かつ Stage 2 で C 支持 → 書く**
なので、**判定不能が「棄却」として読まれると書く方向へ倒れる**。
**事前登録が防ごうとしたバイアスそのもの**であり、無条件で直す。

**これは事前登録の修正である** (DA-SC-19)。`scope_verdict_enum` が
`collect_preregistration()` / `config.json` に含まれる以上、Stage 1 の語彙追加は
**凍結アーティファクトの変更**にあたる。実測前・厳しい側・凍結 ADR の要求の実装、
という 3 点で正当化されているが、**黙って通さない** — `config.json` を再生成し、
修正の事実を Execution Result に明記すること。

`reproducibility-discipline` Skill を Read してから着手すること。

## Scope

### In

**(1) HIGH-3 / DA-SC-19 — Stage 1 の三状態化**

- `STAGE1_OUTCOME_ENUM: Final[tuple[str, ...]] = ("DEFLATION_SUPPORTED", "DEFLATION_REJECTED", "INCONCLUSIVE")`
  を追加し、`collect_preregistration()` に **`"stage1_outcome_enum"`** として登録
  (既存 `scope_verdict_enum` と同じ書き方)。`config.json` を再生成する。
- `Stage1Result` に以下を**追加** (既存フィールドは消さない):

  | フィールド | 型 | 意味 |
  |---|---|---|
  | `stage1_outcome` | `str` | `STAGE1_OUTCOME_ENUM` のいずれか。**load-bearing** |
  | `drop_p5_eligible` | `float` | eligible replicate に限った帯の下端 (**副**、§3:165) |
  | `drop_p95_eligible` | `float` | 同上端 |
  | `median_drop_eligible` | `float` | 同中央値 |
  | `drop_p5_strat` | `float` | **層別**を副として報告 (issue 004 Scope In) |
  | `drop_p95_strat` | `float` | 同上端 |
  | `median_drop_strat` | `float` | 同中央値 |
  | `n_objects_pool_short` | `int` | プール不足だった物体数 (**無音で減らさない**) |
  | `pool_short_objects` | `tuple[str, ...]` | その物体 id |
  | `median_draw_drop` | `float` | median-by-drop draw の sensitivity 併記 (DA-SC-12) |
  | `median_draw_outcome` | `str` | 同 draw での `STAGE1_OUTCOME_ENUM` 値 (**主判定に使わない**) |

- `deflation_supported: bool` は**削除せず**、`stage1_outcome == "DEFLATION_SUPPORTED"` の
  **派生ミラー**として docstring に明記する。
- docstring に **「`not deflation_supported` から『書く』権利を導出してはならない。
  書けるのは `stage1_outcome == "DEFLATION_REJECTED"` のときだけ」** を明記する
  (I-005 がこれを実装する)。

**(2) HIGH-4 / DA-SC-17 — `ScopeVerdict` にフィールド 1 本追加**

- `t_confound_note_required: bool` を追加する。**他のフィールドは改名しない**
  (user 裁定 = 凍結コード側の語彙を正)。
- docstring に「§1 の T/S 非対称 (HIGH-3 反映版) 由来の T 交絡注記が必要か」を書く。

**(3) HIGH-5 — `InternalReference` の所有者を訂正**

- docstring の `Frozen contract only -- I-002 fills the values.` を
  **`I-006 fills the values.`** に訂正する (`issues/006.md` の
  `internal_rho_and_k() -> InternalReference` が正)。**I-002 は低水準 ρ 関数のみ**。

**(4) MEDIUM-1 — 節 anchor の設置**

- ファイル末尾 (現 501 行、dataclass 群で EOF) の後に、**I-002..I-006 用の空の節見出し**を
