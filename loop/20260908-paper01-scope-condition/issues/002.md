# Issue 002: 疎化層 — leader clustering と冗長性 ρ (fidelity pin (a) つき)

verify_level: recheck

## Goal

`design-final.md` §2/§3 の **leader clustering** と **冗長性 ρ** を実装し、
**`leader_cluster_indices(radius=REF_DEDUP, cap=n)` が既存
`greedy_dedupe_indices(cap=n)` と返り index 列まで完全一致する**ことを pin する
(**fidelity pin (a)**)。

## Background

条件 C は「参照集合が**クラスタ代表 1 件ずつで非冗長に覆う canonical なリスト**であるとき」
という**構成**の命題であり、それを外部プール上で作る唯一の装置がこの層である。

**Codex HIGH-4**: 「`leader_cluster ≡ greedy_dedupe` の一致だけでは ARM-A 再現にならない」
— それは正しいが、**この issue が担うのはあくまで (a) の一致まで**である。
セル全体の順序 (`dedupe → cap → draw`) と ARM-A 再現 (fidelity pin (b)) は **I-006** の責務。

**Codex HIGH-1 / MEDIUM-1 (反映済)**: ρ は **S の proxy であって代数的対応物ではない**。
docstring に必ずそう書く。「代数的に対応」と書かない。

## Scope

### In
- `leader_cluster_indices(embeddings, *, cap, radius) -> list[int]`
  - 凍結走査順・単位正規化済み入力前提・`cos.max() < radius` のとき keep・`cap` で打ち切り
  - **既存 `greedy_dedupe_indices` と同一アルゴリズム**の閾値可変版
- `reference_redundancy(embeddings) -> float` = `mean_r max_{r'≠r} cos(r, r')`
  - `|R_o| < 2` のときの値を**明示凍結**し docstring に書く
- `corpus_redundancy(by_object) -> float` = **物体横断の単純平均** (物体重みで加重しない)

### Out
- τ\* の較正 (I-006) / セル配線 (I-006) / Δ 分解 (I-003)
- `paper01_external_audit.py` の編集

## Allowed Files
