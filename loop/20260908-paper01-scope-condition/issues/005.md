# Issue 005: 判定規則 `decide_scope()` — 全域性・非恒真性・F1-F7 優先順位

verify_level: recheck

## Goal

`design-final.md` §3-§5 の scope 判定を**全域関数**として実装し、
**真理値表を網羅する test** と **mutation testing** で非恒真性を示す。
**encoder も統計も使わない純ロジック** issue。

## Background

G1 の I-003 (`decide_external`) と同じ役割・同じ規律。当初案には
**未定義領域**と**到達不能な verdict** が実際にあり、Opus HIGH-2 で切り出された。
本 issue はその教訓をそのまま持ち込む。

**新規の判定語彙を作らない。** セルごとの verdict は**凍結済み `decide_external()`**
が出したものを受け取るだけで、本関数は**それらの組合せ**と F1-F7 を捌く。

**Codex LOW-1 (反映済)**: F1-F7 が同時到達したときの主 reason は
**`FAIL_PRECEDENCE` = (F4, F1, F2, F3, F5, F6, F7)** の順で決める (決定論)。

## Scope

### In
- `decide_scope(stage0, stage1, cells, *, cambridge) -> ScopeVerdict`
  - 出力 (**DA-SC-17 = user 裁定で凍結コード側の語彙を正とする**。当初本文の
    `condition_supported` / `reason` / `fail_branch` は**却下**、下記に読み替える):
    `verdict: str` (`SCOPE_VERDICT_ENUM` = `"WRITE"` | `"DO_NOT_WRITE"`) /
    `deflation_supported: bool` / `condition_c_supported: bool` /
    `single_point_dependent: bool` / `fail_reason: str | None` /
    `notes: tuple[str, ...]` / `t_confound_note_required: bool` (I-001b で追加)
  - **C 支持の必要十分条件** (design-final §3 Stage 2):
    1. `verdict(ARM-S) == NO_VALID_SCORER` かつ `verdict(ARM-A) == PASS`
    2. Ocsai **両分割**で 1 が成立
    3. **τ\* の隣接 1 段**でも 1 が成立
    4. F1-F7 のいずれにも非該当
  - **Stage 1 の三状態を正しく捌く (Codex TASK-PRE HIGH-3 / DA-SC-19、本 issue の核)**:
    `stage1.stage1_outcome` は `"DEFLATION_SUPPORTED"` | `"DEFLATION_REJECTED"` |
    `"INCONCLUSIVE"` の 3 値。
    **`verdict == "WRITE"` を出せるのは `stage1_outcome == "DEFLATION_REJECTED"` のときだけ**。
    **`not deflation_supported` から「書く」権利を導出することを禁止する** —
    `INCONCLUSIVE` も `deflation_supported is False` なので、
    そこから書くと**判定不能が「棄却」に化ける** (`design-final.md:165` / `:251`)
  - F1-F7 の判定と `FAIL_PRECEDENCE` による主 reason の決定

### Out
- 統計計算 / τ\* 較正 / セル構築 (I-006)
- **encoder を使う一切の処理**

## Test Plan
- **encoder 完全非依存**。`ExternalVerdict` 相当の dataclass を直接構築して通す。
- 真理値表は `itertools.product` で全組合せを生成し、**例外なく返る**ことを assert。
- 負例も**必ず同じ判定関数に通す**。dataclass を構築して自分のフィールドを assert しない。
- **恒真な AC を排除する** — `monkeypatch.setattr` で `FAIL_PRECEDENCE` を変えたら
  005-4 の結果が**変わる**ことまで assert する。
