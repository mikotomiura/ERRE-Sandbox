# Issue 004: Stage 1 — deflation 検定 (内部形状への縮小抽出と drop 帯)

verify_level: recheck

## Goal

`design-final.md` §3 Stage 1 を実装する。外部 gold を**内部と同じ形**へ縮小抽出し、
`drop_r` の 5-95 パーセンタイル帯が**内部 C0 pooled drop 0.2350 を含むか**を判定する。

## Background

**これは最も deflating な対立仮説 (「内部の崩落は 41 項目・有効ペア 25 の小標本効果」)
を先に潰す工程であり、判定順序で必ず最初に評価される。**
**この検定が「支持」に倒れると論文 01 は書かない**ので、
**書きたい方向へ倒れやすい設計になっていないか**を特に厳しく見ること。

**Codex HIGH-5 (反映済)**: anchor は **`STAGE1_DRAW_INDEX = 0`** に固定する。
当初案の「median-by-drop draw」は **drop (= outcome) で選ばれた draw** であり、
**外部の outcome で anchor を選んでから小標本検定する** forking-paths 構造だった。
**median draw は sensitivity として併記するのみ。**

## Scope

### In
- `internal_shaped_replicates(contexts, *, replicates, corpus, scheme, seed) -> list[GoldSubset]`
  - 物体あたり **common 1 件**
  - good は `STAGE1_INTERNAL_GOOD_COUNTS` を **`object_weight` 降順の active 物体へ巡回割当**
  - seeded 復元なし抽出。`derive_seed("stage1", corpus, scheme, replicate_index)`
  - **Codex TASK-PRE MEDIUM-2 反映**: `corpus` / `scheme` を**明示引数**にする。
    module global や暗黙の文脈から**推測して埋めることを禁止**する
    (seed が silently 変わると replicate が再現しない)
  - プールが足りない物体の扱いを**明示凍結**する (件数を surface、無音で減らさない)。
    → `Stage1Result.n_objects_pool_short` / `.pool_short_objects` に**必ず出す**
- `stage1_drop_distribution(draw_items, subsets) -> Stage1Result`
  - **pooled AUC を主** (内部と同じ統計量)、**層別を副**として両方
    → 副は `drop_p5_strat` / `drop_p95_strat` / `median_drop_strat` に入れる
  - `drop_r` の 5-95 パーセンタイル / 中央値 / eligible replicate 割合
  - **eligible 限定帯** (`design-final.md:165` の「副」) を
    `drop_p5_eligible` / `drop_p95_eligible` / `median_drop_eligible` に入れる
  - **median-by-drop draw の sensitivity** (DA-SC-12) を
    `median_draw_drop` / `median_draw_outcome` に併記する。**主判定には使わない**
- `stage1_outcome(band, reference_drop, eligible_fraction) -> str`
  — **`STAGE1_OUTCOME_ENUM` の 3 値を返す全域関数** (Codex TASK-PRE HIGH-3 / DA-SC-19、
  **本 issue の核**)。I-001b が契約を用意済:
  - `eligible_fraction <= 0.5` → **`"INCONCLUSIVE"`** (`design-final.md:165` の「判定不能」)
  - 帯が `STAGE1_INTERNAL_DROP_REF` (0.2350) を含む → `"DEFLATION_SUPPORTED"`
  - それ以外 → `"DEFLATION_REJECTED"`
  - **`"INCONCLUSIVE"` を `"DEFLATION_REJECTED"` に丸めてはならない**。
    丸めると `design-final.md:251` の出口表で**「書く」方向へ倒れる**
- `stage1_deflation_supported(...) -> bool` は
  **`stage1_outcome(...) == "DEFLATION_SUPPORTED"` の派生ミラー**として実装する
  (独立に条件を書き直さない)
