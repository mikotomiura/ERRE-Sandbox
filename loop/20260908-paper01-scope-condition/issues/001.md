## Background

G1 では事前登録を I-002 で凍結し、「結果が期待と逆でも `design-final` を開けなかった」
のはこの二重固定が効いたため。本タスクは **B-G1-10 の判断規則が凍結済**で、
**測る前に条件と判定規則を凍結する**ことが binding。**定数がコードと config で
食い違ったまま走ると、事前登録の意味が消える**。

`reproducibility-discipline` Skill を Read してから着手すること。
