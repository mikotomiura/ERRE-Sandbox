# Issue 005: Godot send_perturbation + inbound UI trigger（gdscript）
verify_level: parse

## Goal
Godot `WebSocketClient.gd` に `send_perturbation(...)`（client→server の `WorldPerturbationMsg` frame 送出）と
inbound 発火 UI trigger 1 つを追加。`EnvelopeRouter.gd`（受信 dispatch）は**無改変**（inbound-only kind は
Godot が受信しない=LOW-2）。Python↔Godot は WebSocket のみ。

## Background
- `WebSocketClient.gd`: `CLIENT_SCHEMA_VERSION="0.11.0-m13es3"`（:28）、`_send_client_handshake`（:66）で
  send 経路実証済。send は既存 handshake と同型（JSON frame を ws に送る）。
- `test_envelope_kind_sync.py`（純 Python, CI 常時）: `ControlEnvelope` kind 集合 == `EnvelopeRouter.gd`
  `on_envelope_received` の kind 集合。→ `world_perturbation` を `ControlEnvelope` に入れない限り緑維持
  （HIGH-3 で構造保証）。**`EnvelopeRouter.gd` に `world_perturbation` を足さない**（受信しない）。
- 本機に godot バイナリ無し（`resolve_godot()`→None→skip、CI `-m "not godot"`）→ live 実効 pass は環境 gate（G3）。

## Scope
### In
- `WebSocketClient.gd::send_perturbation(target_agent_id, modality, source_zone, content, intensity,
  correlation_id)`: `WorldPerturbationMsg` 形の JSON を ws に送出（`schema_version` 含む）。
- inbound UI trigger 1 つ（keybind or dev ボタン、既存 dev script 規約に従う）。
- 純 Python 契約 guard: gdscript が組む frame payload の field 集合が Python `InboundEnvelope` adapter で
  validate されることを `test_envelope_kind_sync.py` 同型で検証。
### Out
- `EnvelopeRouter.gd` の inbound 受信 dispatch（**足さない**、LOW-2）。
- headless-godot live send の実効 pass（環境 gate、Godot 実装機=MacBook へ deferred）。
