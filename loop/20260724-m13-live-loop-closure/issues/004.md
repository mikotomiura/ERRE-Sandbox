# Issue 004: Plane G — capture→無改変 run_two_phase_capture replay の byte-parity golden
verify_level: recheck

## Goal
Plane L（live_loop）が吐いた per-tick capture を **無改変 `run_two_phase_capture`** に replay し、
6 桁量子化 checksum の byte-parity を確認する regression guard（W-golden）。organ 経路の非破壊性
（決定論再構成可能）を保証する。**closure 証明ではなく regression guard**（MEDIUM-3、役割差明記）。

## Background
- `run_two_phase_capture`（two_phase_live.py:162）は `observation_factory: Callable[[int], Sequence[Observation]]` /
  `RecordReplayChatClient(recorded=)` / `EmbeddingRecordReplayClient(recorded=)` を受ける。
  → capture から `recorded_observation_factory(tick)` を組んで replay するだけの**純粋再利用**。
- 6 桁量子化 checksum: `ecl_trace_checksum` + `quantise_sampling`（two_phase_live.py:365）。
  Windows(UCRT)⇄Linux(glibc) の libm drift を 6 桁で吸収（`feedback_golden_crossplatform_float_drift`）。
- 既存 golden test の idiom = `test_two_phase_live_golden.py` / `test_ecl_v1_live_golden.py`。

## Scope
