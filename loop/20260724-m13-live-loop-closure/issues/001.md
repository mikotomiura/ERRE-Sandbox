# Issue 001: InboundEnvelope + WorldPerturbationMsg schema + →PerceptionEvent 純関数写像
verify_level: recheck

## Goal
client→server 専用の別 discriminated union `InboundEnvelope`（`WorldPerturbationMsg` を保持）を
`ControlEnvelope`（outbound 13 kind）**無改変**のまま新設し、`WorldPerturbationMsg → PerceptionEvent`
の bounded 純関数写像を提供する。閉包ループの inbound 面の型基盤。

## Background
- `ControlEnvelope`（schemas.py:1388）は 13 kind 全 outbound。inbound kind を混ぜると SCHEMA_VERSION /
  Godot handshake / `EnvelopeRouter` / `test_envelope_kind_sync.py` を巻き込む（HIGH-3）。
- `PerceptionEvent`（schemas.py:724）: `modality`(enum), `source_zone`(Zone), `content`(str),
  `intensity`(_Unit 0-1), `source_agent_id`(str|None), `tick`, `agent_id`。`extra="forbid"`。
- 写像は `traversal_observation_factory`（traversal_live.py:243）と同型（world stimulus → PerceptionEvent）。
