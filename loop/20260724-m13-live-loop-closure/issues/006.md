# Issue 006: W-live correlation-id 到達性 witness の統合（到達性のみ・非計測）
verify_level: recheck

## Goal
correlation-id が `WorldPerturbationMsg → PerceptionEvent → capture → two_phase_firing_summary →
emitted envelope` の各 seam を通過したことを **boolean で assert**（"wiring reached each seam"）。
付随 count = 摂動数 / move envelope 数 / 無改変 `two_phase_firing_summary` 再利用の λ>0 eligible tick 数。
**effect/caused/aha/divergence/verdict を主張しない**（HIGH-2）。二重送出検出も boolean acceptance に含む（HIGH-1）。

## Background
- HIGH-2: 非決定論 live で偶然の movement / 別要因 λ 変化が混じるため boolean「摂動→move→λ符号反転」は
  因果を示さない。→ assert は「同一 corr-id が各 seam を通過した（到達性）」に限定。
- G2: corr-id は `live_loop.py` の per-tick trace 台帳が構造的に保持（PerceptionEvent/MoveMsg に field を足さない）。
  driven ループは tick 同期で index を持つゆえ corr-id↔tick↔seam の対応は構造的。
- `two_phase_firing_summary`（two_phase_live.py:395）を**無改変再利用**（λ>0 eligible / 符号反転 count）。
  これは boolean/count の side annotation であって Done gate でも verdict でもない。

## Scope
### In
- `live_loop.py` の per-tick trace 台帳を完成: corr-id ごとに各 seam 通過を記録し、
  `wiring_reachability_summary(traces) -> dict`（各 seam boolean + count、verdict=None marker）を提供。
- 二重送出検出（同一 tick で move envelope が broadcast キューに 1 通のみ）を boolean で含める（HIGH-1）。
- λ>0 eligible tick 符号反転 count は `two_phase_firing_summary` を再利用（再実装しない）。
### Out
