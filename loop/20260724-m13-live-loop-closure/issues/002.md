# Issue 002: gateway inbound_sink opt-in 配線（None で observational identity）
verify_level: recheck

## Goal
`gateway.make_app` / `ws_observe` / `_recv_loop` に `inbound_sink: InboundSink | None = None` を追加。
`None`（本番 `bootstrap()` 経路）で現状の parse-and-ignore を **observational identity**（close code /
response / ログ / timeout 不変）に保ち、非 None（閉包 root のみ）で `InboundEnvelope` を parse し
sink へ enqueue する。

## Background
- 現状 `_recv_loop(ws)`（gateway.py:497）は `_parse_envelope`（`_ENVELOPE_ADAPTER`=ControlEnvelope）で
  parse し全 non-handshake を "ignored in M2" で破棄（gateway.py:520-531）。
- `ws_observe` は `ws.app.state.runtime` を読む（gateway.py:747）。`make_app`（gateway.py:885）が
  `app.state.runtime` を設定。→ `inbound_sink` も `app.state.inbound_sink` に載せ `ws_observe`→`_recv_loop` に thread。
- `InboundSink`（I1 の `integration/inbound.py`）: asyncio.Queue ラッパ + correlation-id 付与 + enqueue。

## Scope
### In
- `inbound.py` に `InboundSink` クラス追加（`asyncio.Queue`、`push(msg)`=corr-id 付与して enqueue、
  `drain(max_n)` FIFO・overflow=drop-oldest・単調増加 seq、LOW-1 policy）。
- `make_app(runtime, *, auth_config, inbound_sink=None)` → `app.state.inbound_sink = inbound_sink`。
- `ws_observe`: `ws.app.state.inbound_sink` を読み `_recv_loop(ws, inbound_sink=...)` に渡す。
- `_recv_loop(ws, *, inbound_sink=None)`: `inbound_sink is not None` の時のみ frame を `InboundEnvelope`
  adapter で先に parse 試行 → 成功で `sink.push` して continue、失敗で既存 ControlEnvelope 経路へ fall through。
  `None` では**既存経路と分岐前 byte 一致**（新 parse を一切実行しない）。
### Out
- driven ループ（I3）で sink を drain する側。Godot 送信（I5）。
