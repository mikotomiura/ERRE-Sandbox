# Issue 004: 統計層 — within-object 層別 AUC / 抽出集約 / bootstrap (encoder 非依存)
verify_level: recheck

## Goal

`design-final.md` §1 / §5 の統計手続きを実装する。**主統計量は within-object 層別 AUC**、
抽出は**各 draw で boolean を決めてから集約**、bootstrap は**層 = (物体 × クラス)**。
**encoder 非依存**で、stub rarity closure と numpy だけで test できる形にする。

## Background

Opus **HIGH-4**: 内部 gold は 16 物体が common をちょうど 1 件ずつ持つ構造ゆえ
good×common 400 ペア中**同一物体ペアは 25 = 6.25%** で、**内部 pooled AUC は実質「物体間」統計**。
Cambridge pooled は **50.06% が同一物体内**。**pooled のままでは別の量を比べることになる。**

Opus **HIGH-5**: 周辺中央値 (`median(AUC_full)` と `median(AUC_LAO)` を別々に取る) は
**どの抽出にも存在しない配置で判定しうる**。

Opus **HIGH-8**: 落下量の CI と `P(drop≤0)` が外部で未登録だった。

## Scope

### In
- `auc_stratified(scores, labels, objects)` — 物体内 AUC を `n_good(o)·n_common(o)` 重みで平均。
  `controls.auc` を **frozen のまま呼ぶ** (再実装しない)
- draw 集約 — 各 draw で `eligible_b` / `engaged_b` / `collapsed_b` を確定 → 候補レベルは
  **割合 ≥ 0.5**。報告は崩落抽出割合 / `median_b(drop)` / **5-95 パーセンタイル**
- bootstrap — **層 = (物体 × クラス)**、`N_RESAMPLES`/`CI_ALPHA` を import、
  `default_rng(SEED)`、**中央値 draw にのみ適用**。`drop` の CI と **`P(drop ≤ 0)`** を出す
- 5 つ組 — `AUC_membership := auc(1 − m, label_good)` (**向きを凍結**、Opus HIGH-9) /
  `potency` / クラス別 near-dup 率 / **LAO で落ちた anchor の平均本数 / |R_o|** (Opus MEDIUM-3)
- **permutation p は抽出ループの外**。`corpus × 候補 × アーム` につき代表 1 回 (Opus MEDIUM-4)

### Out
- adapter / anchor 構築 / encoder (I-005 以降)
