# Issue 007: fidelity pin — 外部 harness が「同じ計測器」であることの証明
verify_level: recheck

## Goal

外部 harness に**内部データ**を流し込むと、封印済み `diagnostic.json` の行を再現することを
機械的に示す。これが緑でなければ「外部で崩落しなかった」の解釈が成立しない
(別の計測器を当てただけになる)。

## Background

Phase 4b の Option A で使った「sibling driver を fidelity test で pin する」規律と同型。
本セッションで **C0 = 0.9900 / 0.7550、C4 = 0.9950 / 0.7050 を CPU・offline で完全再現済**。
その再現を**コードに固定**する。

  **C4 = `auc_full` 0.9950 / `auc_lao` 0.7050** を再現する。
  `eval` marker + `pytest.importorskip("sentence_transformers")`

  結果は `experiments/20260907-paper01-g1/results/fidelity.json`
- 併せて内部側の記述的共変量も記録する
  (membership AUC / near-dup 率 good 0.000 vs common 0.500 / potency 8/41)
