# Issue 001: 外部コーパス取得層と形状/ライセンス audit
verify_level: recheck

## Goal

2 つの外部コーパスを取得し、**SHA-256・行数・列/キー・クラス件数・ライセンス表示**を
機械的に `source-audit.json` へ書き出す。`.steering/.../decisions.md` に記録した
Gate 0 実測件数と一致しなければ **exit 1 で落ちる** (= Stop 判定が最初に出る)。

## Background

`feedback_source_stock_precheck_before_retrain`: **flag の存在 ≠ 在庫保証**。
本セッションで subagent が一次確認した件数 (下表) は**人手確認**であり、成果物ではない。
同じ数字を**コードが再取得して再計算し、一致を assert する**ところまでやって初めて Gate 0。

| corpus | 実測 |
|---|---|
| Cambridge bowl | 3,380 行 / good 32 / common 2,082 |
| Cambridge paperclip | 3,650 行 / good 47 / common 2,047 |
| Ocsai main2 (train+val+test 連結) | 20,121 行 (全 AUT) / brick 5,162 / paperclip 1,385 / bottle 839 / shoe 382 |

## Scope

### In
- `scripts/paper01_fetch_sources.py` — 取得 + SHA-256 + 形状 audit。**stdlib + numpy のみ**
  (xlsx は `zipfile` + `xml.etree.ElementTree`。`openpyxl` / `pandas` は使わない = DA-G1-17)
- Cambridge の原 `.xlsx` **2 件を byte 無改変で** `experiments/20260907-paper01-g1/data/raw/` へ配置
  (CC BY-NC-ND 4.0 Sec.2(a)(1)(A) の範囲。DA-G1-3)
- `experiments/20260907-paper01-g1/data/raw/NOTICE.md` — 作成者 / 著作権表示 /
  ライセンス参照 / 原典 URI (CC BY-NC-ND 4.0 Sec.3(a) の attribution 要件)
- **Ocsai は再配布しない** — 取得スクリプト + SHA-256 のみ。取得不能時は
  `"status": "source_unavailable"` を **audit JSON に記録して exit 0** (黙って落とさない)
- `.gitattributes` に `experiments/**/data/raw/** -text -whitespace` を追記
  (現状 `*.xlsx` / `*.csv` の規則が無く、eol 変換で SHA-256 が壊れうる)
- `experiments/20260907-paper01-g1/data.md` — provenance + SHA-256 + ライセンス

### Out
- 二値化・anchor 構築・スコアリング (I-002 以降)
- **スコアの計算は一切しない** (forking-paths seal)
