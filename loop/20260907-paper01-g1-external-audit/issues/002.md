## Scope

### In
`scripts/paper01_external_audit.py` の module-level `Final` 定数として:

- `CORPORA` — 識別子・取得 URI・SHA-256・形式 (`xlsx` / `jsonl`)
- **二値化** — Cambridge: 値のある rater 全員が 1 → common / 全員 ≥3 → good /
  0 を含む・2 を含む・band 跨ぎ・`Responses` 欠損 → 除外。
  Ocsai: encoded == 10 → common / encoded ≥ 40 → good / 11-39 → 除外
- **分割** — Cambridge `int(id) % 2` / Ocsai は連結後の 0-origin 行 index parity。
  `split0` = anchor 構築、`split1` = 採点 + gold
- **anchor 3 アーム** (DA-G1-18 が DA-G1-13 を supersede) —
  **ARM-A** = A1 プールを dedupe 後 **30 件を seeded 無作為抽出 (B=50)**・**中央値で判定 (verdict)** /
  **ARM-B** = A1 プール全件 (上限なし・sensitivity) /
  **ARM-C** = (A1∪A2) dedupe 後 30 件 (**Ocsai のみ**・sensitivity)
- `ANCHOR_DRAWS = 50` と抽出用 RNG seed (= `SEED`)。**抽出は dedupe 後のプールから行う**
  (greedy 走査順の自由度を消すため)
- **抽出件数 `k = min(N_R_MAX, |pool|)`** (Codex HIGH-3)。`|pool| < 30` なら全件を使い
  `draws_effective = 1` を記録する
- **`OCSAI_PRIMARY_OBJECTS` = 全 21 物体** / `OCSAI_SENSITIVITY_OBJECTS` = brick/paperclip/bottle/shoe
  (Codex HIGH-2)。**物体を落とす条件は `|R_o| < N_R_MIN` または gold クラス不足のみ**。
  物体の順序と件数も config に固定する
- **入れ子の不確実性** (Codex HIGH-5) — verdict は **draw 中央値の点推定のみ**、
  draw の 5-95 パーセンタイルと中央値 draw の bootstrap CI は**報告専用**。**合成しない**
- **engaged 条件 = `median_b(potency) > 0`** (Codex MEDIUM-3、any draw ではない)
- **ARM-X** (source-crossed, `paperclip` のみ) の定義 — anchor = Cambridge / gold = Ocsai (Codex HIGH-1)
- **`source_unavailable` は verdict ではなく incomplete status** (Codex HIGH-4)
- **候補ラダー** — `C0` `C1` `C2-lenctrl` `C3-MiniLM` `C3-e5-small` `C3-bge-small` `C5-jaccard`
  `C6-tfidf` の 8 件。**`EMBEDDING_FAMILY` = 前 6 件** (primary verdict の対象、DA-G1-8)。
  `C4` は外部に対応物が無く**欠番**と明記
- `MIN_CLASS_N = 16` / floor は `constants.AUC_FLOOR` を**再定義せず import** /
  `CI_ALPHA` `N_RESAMPLES` `REF_DEDUP` `REF_FREQ_MIN` `N_R_MIN` `N_R_MAX` も同様
- `PYTHONHASHSEED` の固定値 (`SEED` ファイルと一致)
- `experiments/20260907-paper01-g1/{SEED,config.json,env.md}`
