# Issue 003: 判定規則 `decide_external()` — 全域性と非恒真性 (encoder 非依存・純ロジック)
verify_level: recheck

## Goal

`design-final.md` §6 の判定規則を**全域関数**として実装し、**真理値表を網羅する test** と
**mutation testing** で非恒真性を示す。**encoder を一切使わない純ロジック** issue。

## Background

Opus TASK-PRE 代替レビュー **HIGH-2** で、当初案の判定規則に**実際に踏みうる未定義領域**が
見つかった。`¬engaged(c) ⟹ auc_lao = auc_full ≥ floor ⟹ ¬collapsed(c)` が恒等的に成り立つため、
「engaged と ¬engaged が混在し、engaged なものが全部 collapsed」で**どの規則も発火しない**。
さらに **eligible な potency=0 候補が 1 つあるだけで `NO_VALID_SCORER` が到達不能**だった。
`REF_DEDUP=0.90` を 4 encoder に同一適用するので、encoder 境界で potency が割れるのは既定。

**M-10 に従い、この load-bearing な純ロジックを独立 issue に切り出す。**

## Scope

- **encoder を使う一切の処理**
