# Issue 001: society.py の additive seam 2 本（two_phase_knob / on_runtime_ready）
verify_level: recheck

## Goal
`society.py::run_society_loop` に **additive kwarg を 2 本だけ**足し、既定値で現状と
**byte-identical** を保ったまま、(a) knob-on cycle を外から注入でき、(b) driver が構築した
`WorldRuntime` を **最初の observation drain より前**に外へ渡して await できるようにする。

## Background
- `run_society_loop` は `WorldRuntime` / `CognitionCycle` を関数内部で構築し、返り値にも含めず
  **外部へ一切公開しない**（society.py:1287-1320）。gateway は具体的 runtime 参照を要求する
  （`_RuntimeLike.recv_envelope` / `layout_snapshot`、gateway.py:186）ので、無改変では outbound を
  Godot に出せず knob の注入口も無い（ADR §3 鍵 1、`decisions.md` DA-SLC-1）。
- `TwoPhaseKnob` は presence-only marker（gain を持たない、two_phase.py:117）。共有 cycle 1 個でも
  逐次 sorted step なら per-agent `AgentState` から sampling が組まれる（Codex M-4 是認）。
- **Codex H-1**: 同期 callback では supervisor が `make_app(runtime=world)` を起動する前に tick0 の
  drain が走りうる。`Awaitable` を許す **readiness barrier** にし、**dialog attach 後・最初の
  observation drain 前**に置く。名称は `on_runtime_ready`（Codex L-3）。
- **Codex M-5**: これは gateway が `recv_envelope` / `layout_snapshot` に使うための
  **construction exposure** であり、hook は runtime を mutate しない（doc/test で縛る）。

## Scope
### In
- `run_society_loop` に `two_phase_knob: TwoPhaseKnob | None = None` を追加し
  `CognitionCycle(two_phase_knob=…)` へ素通し。
- `run_society_loop` に
  `on_runtime_ready: Callable[[WorldRuntime], Awaitable[None] | None] | None = None` を追加。
  dialog scheduler / generator の attach 後・最初の observation drain 前に 1 回だけ呼び、
  返り値が awaitable なら await する。`None` なら一切呼ばない。
- docstring に「construction exposure、hook は runtime を mutate しない」契約を明記。
### Out
- router / 閉包 root / witness / Plane G（I2 以降）。
- 3 本目以降の kwarg（`dialog_envelope_sink` 等）は **Stop 条件 S1**。

## Execution Result

### 実装内容

`src/erre_sandbox/integration/embodied/society.py` の `run_society_loop`（frozen module,
additive のみ）に kwarg を **2 本だけ**追加した。ループ本体のロジックは不変。

1. `two_phase_knob: TwoPhaseKnob | None = None`（署名）→ 既存の
   `CognitionCycle(...)` 呼び出しへ `two_phase_knob=two_phase_knob` として素通し
   （`TwoPhaseKnob` は `erre_sandbox.erre.two_phase` の presence-only marker、実コード
   `cognition/cycle.py:448` を読んで kwarg 名を確認した上で配線）。
2. `on_runtime_ready: Callable[[WorldRuntime], Awaitable[None] | None] | None = None`
   （署名）→ 呼び出し位置は `world.attach_dialog_scheduler` / `attach_dialog_generator`
   の直後、最初の cognition window の観測 drain（`inject_observation`）より前。1回だけ
   呼び、返り値が `Awaitable` なら await する。実装は独立ヘルパ
   `_invoke_runtime_ready_hook` に抽出した（`run_society_loop` 本体へ直接 if/isinstance を
   インラインすると ruff C901（cyclomatic complexity 10→12）に抵触したため、本ファイル
   既存の Layer2 抽出規律に倣って分離）。docstring に「これは gateway 側
   `recv_envelope`/`layout_snapshot` 用の construction exposure であり、hook は runtime
   を mutate しない」契約を明記した。

### DA-SLC-4（既存テストの allowlist 1 語追加）

実装中に、ADR §4 の型契約どおり `two_phase_knob: TwoPhaseKnob | None` と厳密に型付けすると
`erre_sandbox.erre.two_phase.TwoPhaseKnob` の import が必要になり、これが
`tests/test_integration/test_m2_society_spend_guard.py` の閉じた import allowlist
（`_ALLOWED_ERRE_PREFIXES`）に無く、2 テスト（同ファイルの
`test_m2_society_no_measurement_computation` と `test_m2_society_selfother.py` の
`test_self_other_no_measurement_computation`）が赤くなることを検出した。executor prompt の
「触ってはいけない：既存テスト」は過剰制約であり、ADR §4 / issue 001 の「触らない」列挙は
organ・production `bootstrap.py`・`gateway.py`・`inbound.py`・`live_loop.py`・
`society_live.py`・`ControlEnvelope`・SCHEMA_VERSION・既存 golden であって既存 test guard は
含まれないとの裁定を受け、`_ALLOWED_ERRE_PREFIXES` に `"erre_sandbox.erre.two_phase"` を
1 語追加した（`_DENIED_IMPORT_SUBSTRINGS` および他の allowlist 要素は無改変）。理由を
docstring に併記: (a) construction/sampling 変調であって measurement-line ではない
（`TwoPhaseKnob` は gain を持たない presence-only marker）、(b) society.py は cycle へ
素通しするだけで knob の意味論を持たない、(c) 触らない organ `cognition/cycle.py` が既に
同じ型を同じ場所から import している、(d) allowlist は閉列挙のまま・denylist は無改変。
SSOT 参照として本判断 `decisions.md` DA-SLC-4 を docstring に明記した。
