# Issue 006: W-N4 Plane G — 無改変 `run_society_loop` への replay byte-parity + request conformance
verify_level: recheck

## Goal
live capture（Plane L）を **無改変の `run_society_loop`** へ replay して
`ecl_trace_checksum` / `event_log_checksum` の **byte-parity** を取り、
さらに **replay 側 spy** で prompt drift を検出する（Codex H-4）。

## Background
- **replay 時 `RecordReplayChatClient._used` は commit 済み call**（loop.py:230）。
  よって knob-on capture を **knob-off の無改変 `run_society_loop`** へ replay しても
  checksum は一致する（knob は sampling のみ変調、trajectory を変えない）。
- 逆に **prompt 一致は恒真になってしまう**（committed prompt をそのまま持つ）ので、
  prompt drift の検出には **replay 側で実際に再構成された prompt を記録する spy** が要る
  （I7 の `RequestConformance*` idiom の N 体版）。
- **Codex H-4**: 照合対象は `(agent_id, window, system_prompt, user_prompt)` と embedding request。
  **`sampling` は明示除外**（knob-on capture を knob-off replay するため一致しない）。
  knob-on 側 sampling の pin は既存 `two_phase_firing_summary` の `record_knob_on_pinned` で annotation。
- **Codex M-3**: byte-parity は **scripted in-process perturbation に限定**。
  実 Godot / WS 到着時刻 / LLM latency は外部非決定源で replay 対象外。
  「wall-clock real-time live session ではない」境界を明記する。
- float は 6 桁量子化。**生 serialized 埋め込み文字列（`model_dump_json`）は素通りする**ので
  projection 境界で再量子化（PR #55/#76 の轍、`feedback_golden_crossplatform_float_drift`）。

### 実測（AC ↔ 結果）
- **AC1** `test_plane_g_replay_checksums_byte_identical` — knob-on capture (N=3 × 12→test は 3 window)
  → knob-off 無改変 replay で `ecl_trace_checksum` / `event_log_checksum` **両方 byte 一致**。
- **AC2** `test_plane_g_replay_touches_no_llm` — 全 agent の `inner_invocations == 0` +
  embedding も 0。非恒真化のため「9 request を実際に供給した」も同時に assert。
- **AC3** `test_request_conformance_prompts_match_excluding_sampling` — 一致 + `compared_fields`
  に `sampling` 無し / `excluded_fields == ["sampling"]` / 理由文字列一致 /
  spy が sampling を**実際に観測している**ことも assert（「取れないから除外」ではない）。
- **AC4** `test_request_conformance_detects_prompt_drift` — 負例 3 本。(a) committed user_prompt を
  1 文字変更 → `llm_first_drift` が `(agent_id, window=1, fields=["user_prompt"])` を特定。
  (b) embedding request 1 文字変更 → 検出。(c) **committed observation を 1 文字変更した
  replay 側 drift → geometry checksum は緑のまま conformance だけ落ちる**（H-4 の本丸）。
- **AC5** `test_self_other_slot_reproduced_on_replay` — slot が **populated** であることを先に
  assert してから一致を確認（None 同士の一致でない）。pin を潰した負例で False になることも確認。
- **AC6** `test_no_new_nondeterminism_sources` — live root は findings 0。負例 fixture
  (uuid4 / datetime.now / .keys() / .values() / set()) で全種別を検出、clean fixture では 0。
- **AC7** `test_embedded_json_floats_are_requantised` — projection 後の埋め込み JSON の
  全 float が 6 桁以内。負例 1: 生 record は 6 桁超の float を持ち、naive `json.dumps` は素通り。
  負例 2: sub-quantum(4e-10) 摂動は bytes と `event_log_checksum` が不変 / supra-quantum(1e-3) は
  両方変化（両方向で非恒真）。side file の round-trip も確認。
- **AC8** `test_firing_annotation_is_non_gate` — `verdict is None` / `hard_gate is False` /
  per-agent も同様 / 禁止語彙が key 空間に現れない / `record_knob_on_pinned is True`。
  実測 `fail_mode="no_eligible_tick"`（scripted 摂動下で agent が settle）= 非 gate なので honest に記録。
- 追加 `test_ledger_factories_group_by_routed_agent_id` — 誤バケツ化 fixture で
  `routed_agent_id` 側の factory に入り `target_agent_id` 側は空、を pin（DA-SLC-8 の恒真性回避）。
