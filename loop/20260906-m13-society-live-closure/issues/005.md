# Issue 005: W-N2 — ミラー（prompt-level self-other context）が live 認知呼び出しに乗った witness
verify_level: recheck

## Goal
M2 Layer2 のミラーが **live 閉包経路の cognition call に実際に乗った**ことを boolean で示す。
これは **construction wiring の witness** であって、心の理論でも内部状態の推定でも
効果の測定でもない（Codex L-1）。

## Background
- ミラーは organ の既存 public seam
  `step_cognition_once(agent_id, *, self_other_context=…)`（tick.py:1706）に既に載っており、
  live 経路では `run_society_loop(self_other_enabled=True)` が society 自身の
  `_build_window_self_other_contexts` → `build_self_other_context` で構築する。
  → **live root はミラーを再実装しない**（SSOT が society 側にある = 案 B 採用の主根拠）。
- `RecordedLlmCall` は `system_prompt` / `user_prompt` を保持する（loop.py:127-128）ので、
  「segment が live prompt に乗ったか」は committed record から直接読める。
- Layer2 の landed 規律を継承: **新規 LLM call を作らない**（segment は既存 prompt に相乗り）、
  **episodic memory との disjointness**、**echoing mock で non-vacuous 化**。
- **Codex M-4**: acceptance に **call 数 = N × ticks 不変**と **per-agent attribution** を pin。
- **Codex L-2**: disjointness の検査対象を **observation 由来の memory field への混入**に限定し、
  echo mock の raw response / utterance に marker が出るケースと混同しない。

## Scope
### In
- committed `RecordedLlmCall.user_prompt` に対する segment 検出（window >= 1 / N >= 2）。
- disjointness 検査（observation 由来 memory field に限定）。
- call 数 / per-agent attribution の pin。
- annotation: 非空 segment を持つ (agent, window) の plain count（非 gate、`verdict` は `None`）。
### Out
- segment の**内容**の良し悪しの評価（= measurement。禁止）。
- ミラーが行動を変えたかどうか（= effect / detectability。**凍結第2リンク**、非測定）。
- Plane G の prompt conformance（I6）。

## Acceptance Criteria（AC↔test）
- AC1: N=3 / window >= 1 の live 駆動で、committed `user_prompt` に **非空の self-other segment** が
  含まれる (agent, window) が 1 件以上ある
  → `test_society_live_loop.py::test_self_other_segment_present_in_committed_prompt`
- AC2: window 0 では segment が空（strict prefix filter が効いており self / future が漏れない）
  → `test_society_live_loop.py::test_self_other_segment_empty_at_window_zero`
- AC3: segment が **observation 由来の memory field に混入していない**（disjointness、Codex L-2）。
  **echoing mock**（LLM が segment を echo する mock）で non-vacuous 化する
  → `test_society_live_loop.py::test_self_other_segment_disjoint_from_observation_memory`
- AC4: LLM call 数が **N × ticks**（= 3 × 12 = 36）で、`self_other_enabled` の on/off で**同数**
  （新規 call を作らない、Codex M-4）
  → `test_society_live_loop.py::test_llm_call_count_is_n_agents_times_ticks`
- AC5: 各 call が正しい agent に帰属する（per-agent attribution、逐次 sorted step ゆえ一意）
  → `test_society_live_loop.py::test_per_agent_call_attribution_is_unique`
- AC6: witness に `verdict: None` があり、effect / detectability / divergence を名乗るキーが無い
  → `test_society_live_loop.py::test_mirror_witness_has_no_verdict`

### 非恒真性の担保（DA-SLC-8 の教訓を AC に明示反映）

各 witness に「**壊れる負例**」を test で対にした。

| AC | 負例 | witness の出力 |
|---|---|---|
| AC1 | 同構成で `self_other_enabled=False` の ablation 実走 | `any_agent_window_has_segment` = **False** / `segment_present_count` = **0** |
| AC2 | window 0 の committed `user_prompt` に segment を偽造注入 | `window_zero_segment_absent` = **False** |
| AC3 | observation 由来 memory row に marker を混入 / bullet 行のみの部分混入 | `segment_absent_from_observation_memory` = **False**（両方） |
| AC4 | 同一 agent に call を 1 本水増し | `llm_call_count_equals_agents_times_windows` = **False** |
| AC5 | 2 agent の committed call 列を入替 / 同一 (agent, window) を重複 | `segment_never_names_observer` = **False** / `agent_window_pairs_unique` = **False** |

加えて `every_nonempty_segment_names_a_roster_agent` を **vacuity guard** として持たせた
（render 契約が drift して parse が空になった場合、命名系の boolean が黙って True に
なるのを防ぎ、代わりにこの boolean が False へ倒れる）。

### disjointness の検査対象限定（Codex L-2）

- 検査するのは **observation 由来 memory field のみ** =
  `SocietyRunResult.memory_mutations[*].content` (`kind='episodic'`)。
  この行は `cognition/cycle.py::_write_observations` が **pre-prompt observation からのみ**
  書く（record mode は reflection 無効なので他テーブルは書かれない）。
- **echo mock の raw response / utterance に marker が出るケースは違反にしない**。
  `llm_output_segment_echo_count`（plain count、非 gate）として**別キー**で報告し、
  docstring と `note` に「これは prompt の echo であって disjointness 違反ではない」と明記。
- 実測（N=3 / 3 window / echoing mock）: `llm_output_segment_echo_count=6`、
  `observation_memory_row_count=11` (`{"episodic": 11}`)、
  `segment_absent_from_observation_memory=True`、
  `observation_memory_rows_carrying_segment=[]`。
