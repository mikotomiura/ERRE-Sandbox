# Issue 004: W-N1 到達性 witness + W-N3 outbound ownership witness
verify_level: recheck

## Goal
「配線が届いた」を **boolean / count だけ**で述べる witness を実装する。
`verdict` は明示 `None`。effect / divergence / detectability / floor / scorer は emit しない。

## Background
- **W-N1**（PR #89 HIGH-2 の継承）: seam 粒度は非一様。
  `perturbation` / `perception` / `capture` は **per-correlation**、
  `firing_summary` / `same_tick_envelope_observed` は **tick-level co-occurrence** であって
  per-correlation causation ではない（correlation-id は outbound wire protocol に到達しない）。
- **Codex M-2**: 到達性の母集団は **injected のみ**。unknown target は `rejected` count、
  overflow は `dropped` count として**別枠**に置く。
- **Codex H-2**: broadcast 側 ledger を `WorldRuntime.drain_envelopes()` の**事後観測で取らない**。
  gateway `_broadcaster` が同じ queue を `recv_envelope()` で消費するので race-dependent になる。
  **gateway が実際に fan-out したものを記録する session** から取る（gateway は無改変）。
- **Codex H-3**: dialog scheduler は `dialog_initiate` / `dialog_turn` / `dialog_close` を
  `world.inject_envelope` 経由で broadcast queue に入れる **正当な第二の生産者**。
  society へ 3 本目の kwarg を足さずに wrap する手段が無いので、
  **gate は cognition kind 限定**（`move` / `speech` / `animation` / `agent_update`）に縮小し、
  `dialog_*` は **plain count の annotation（非 gate）** に置く。除外理由をコードに明記する。
- live root はそもそも駆動ループ本体を持たず outbound に触れないので、
  `inject_envelope` 非呼び出しを spy で pin すれば cognition 側の単一 owner 性は担保される。

## Scope
### In
- `society_wiring_reachability_summary(...)`:
  - per-agent / per-correlation の seam boolean（`injected` 母集団のみ）。
  - `rejected_count` / `dropped_count` / `injected_count` の plain count。
  - `no_double_send`（cognition kind 限定の多重集合一致）。
  - `dialog_envelope_counts`（annotation、非 gate）。
  - `verdict: None` と、**reachability is not causation** / seam 粒度非一様 / dialog 除外理由を
    書いた `note` 文字列。
- consume 側 ledger の収集口（gateway 無改変で fan-out 先を記録する session）。
- live root が `inject_envelope` を呼ばないことの spy。
### Out
- ミラー witness（I5）、Plane G（I6）、firing summary の per-agent 化（I6 の annotation で扱う）。

## Acceptance Criteria（AC↔test）
- AC1: injected な全 correlation-id が **狙った agent** の 3 per-correlation seam を通過
  （`perturbation` / `perception` / `capture` すべて `True`）
  → `test_society_live_loop.py::test_reachability_per_correlation_seams_all_true`
- AC2: `rejected` / `dropped` の correlation-id は **到達性の母集団に入らない**
  → `test_society_live_loop.py::test_reachability_population_is_injected_only`
- AC3: cognition kind（`move` / `speech` / `animation` / `agent_update`）の多重集合が
  enqueue 側（`decisions[*].envelope_provenance`）と **consume 側記録**で一致
  → `test_society_live_loop.py::test_cognition_kind_multiset_matches_consume_side_ledger`
- AC4: `dialog_*` は gate に含まれず annotation の plain count として出る（除外が明示されている）
  → `test_society_live_loop.py::test_dialog_envelopes_are_annotation_only`
- AC5: live root は `inject_envelope` を**一度も呼ばない**（spy で 0 回）
  → `test_society_live_loop.py::test_live_root_never_calls_inject_envelope`
- AC6: summary に `verdict` キーがあり値は `None`。effect / divergence / floor / score /
  detectability を名乗るキーが**存在しない**
  → `test_society_live_loop.py::test_reachability_summary_has_no_verdict`
- AC7: 同一 tick に複数摂動が乗った場合、tick-level seam は全員が同じ値を読む
  （over-count ではなく by construction であることを明記）
  → `test_society_live_loop.py::test_tick_level_seams_are_shared_within_a_tick`
