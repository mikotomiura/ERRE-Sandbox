# Issue 003: 閉包 composition root + supervisor（N 体 live セッションが起動して回る）
verify_level: recheck

## Goal
`society_live_loop.py` を **閉包専用の薄い composition root** として完成させ、
knob-on + `self_other_enabled=True` + router factories で **`run_society_loop` をそのまま live の
駆動ループとして回す**。`on_runtime_ready` で得た `WorldRuntime` を gateway に渡し、
gateway serve と駆動を**同一 event loop の `TaskGroup`** で監督する。

## Background
- ADR §1: **駆動ループを二本のままにせず一本にする**。live 側は独自 scheduler を持たない。
- **Codex H-1**: gateway app の構築・起動は `on_runtime_ready` の中で完了させ、その await が
  返ってから最初の window に入る（readiness barrier）。
- 既存前例 = `live_loop.supervise_live_loop`（gateway serve + driven を同一 `TaskGroup` で監督、
  driven 完了で serve task を cancel、`CancelledError` を suppress）。`gateway_serve` は
  caller 注入（production は uvicorn、test は軽量 stub）。
- 事前登録定数: **N=3**（`society_live.py` の `a_kant` / `a_nietzsche` / `a_rikyu`）、
  **`n_cognition_ticks=12`**（`SOCIETY_LIVE_N_COGNITION_TICKS`）。
- LLM 面は `society_live.run_society_live_capture` と同じ `ThinkOffChatClient` →
  `RecordReplayChatClient` の包み方を**再利用**（`society_live.py` は無改変）。

## Scope
### In
- `build_society_live_world(...)` — agent_states / personas / store / embedding / llms /
  router / knob を束ねる construction。`society_live.py` の固定 constructors を再利用。
- `run_society_live_loop(...)` — `run_society_loop(two_phase_knob=…, on_runtime_ready=…,
  observation_factories=router.observation_factories(…), self_other_enabled=True, …)` を呼び、
  `SocietyRunResult` と router ledger を束ねた結果型を返す。

  `on_tasks_scheduled` 相当の testing seam を持ち、両 task が同一 loop であることを test から assert できる。
- `knob=None` fidelity 経路（organ drift pin）: knob を渡さないと I1 AC1 と同じ byte-identical に戻る。
### Out

## Acceptance Criteria（AC↔test）
- AC1: gateway app が **最初の window より前**に構築・起動され、駆動が始まる
  （readiness barrier が効いている、Codex H-1）
  → `test_society_live_loop.py::test_gateway_started_before_first_window`
- AC2: gateway serve task と駆動 task が **同一 event loop** で走る
  → `test_society_live_loop.py::test_serve_and_drive_share_one_event_loop`
- AC3: 駆動完了で serve task が cancel され `TaskGroup` が例外なく閉じる。
  いずれかの task の**真の例外**は `ExceptionGroup` として伝播する
  → `test_society_live_loop.py::test_supervisor_cancels_serve_and_propagates_real_errors`
- AC4: `knob=None` で回すと I1 AC1 と同じ byte-identical（organ drift pin）
  → `test_society_live_loop.py::test_live_root_knob_none_fidelity_byte_identical`
- AC5: N=3 / 12 window の駆動が完走し、各 agent の decisions が 12 件ずつ、
  `cognition_step_order` が sorted 順の繰り返しになる
  → `test_society_live_loop.py::test_live_root_drives_three_agents_twelve_windows`
- AC6: gateway に渡した runtime と society が構築した runtime が**同一インスタンス**
  （第二チャネルが無い）
  → `test_society_live_loop.py::test_gateway_and_driver_share_same_runtime_instance`
